Restaurant Reservation - Android Application

This project is my [bachelor's thesis](http://cv.kntu.ac.ir/saeedfarzi/category/10) at K. N. Toosi University of Technology in 2020. It was developed as an Android application using Java and XML. The application allows customers to browse and switch between various restaurants, view their menus, place meal orders, and have them delivered. Additionally, it provides features such as real-time order tracking, user authentication, and a seamless user interface to enhance the overall dining experience.
